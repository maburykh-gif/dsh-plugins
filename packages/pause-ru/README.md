# pause-ru — пауза DSH по-русски

Русский форк [`dsh-pause`](https://github.com/better-er/dsh-pause) для DeepSeek Harness 0.2.2-rc.1.
Логика та же, интерфейс — на русском.

## Зачем

DSH вызывает инструменты и отвечает непрерывно. Вклиниться в поток штатной
репликой почти невозможно: модель отвечает быстрее, чем человек печатает.
`dsh-pause` подвешивает агента ровно перед следующим шагом — после раунда
инструментов и **до** отправки следующего запроса к модели, — и ждёт Enter.

`pause-ru` делает то же самое, но все надписи и сообщения об ошибках русские:
кнопка «Пауза» / «Пауза вкл.» в строке инструментов composer, полоса
«Приостановлено · Enter или клик — продолжить», подсказки и ошибки.

## Что видно в интерфейсе

*кнопка в composer* — `Пауза` / `Пауза вкл.`;

*полоса паузы* — `Приостановлено · Enter или клик — продолжить`;

*подсказка* — `Нажмите Enter ещё раз, чтобы продолжить`;

ошибки — `Предыдущее сообщение ещё отправляется — нажмите Enter чуть позже`,
`Файловые вложения нельзя отправить с репликой — выберите заново` и т. п.

## Установка

Пакет ставится менеджером плагинов DSH (Settings → Плагины) или инструментом
`plugin_manager`; ребут DSH не нужен, достаточно обновить страницу.

Из локальной папки:

```powershell
# target — папка пакета
plugin_manager install_bundle "D:\Deepseek\market-plugins\packages\pause-ru"
```

Из индекса рынка: `https://raw.githubusercontent.com/maburykh-gif/dsh-plugins/main/market/index.json`.

Важно: **нельзя** держать включёнными одновременно `dsh-pause` и `pause-ru` —
оба вставляют один и тот же узел `agent/pre-step` и один слот composer.
Сначала отключите апстрим.

## Использование

1. Нажмите «Пауза» в строке инструментов composer — кнопка станет «Пауза вкл.».
   То же делает клавиша Pause.
2. Дальнейшие продолжения после инструментов будут останавливаться на точке паузы.
3. Чтобы продолжить: голый Enter в основном поле (пусто — незаметно, с текстом
   или картинками — как реплика), либо клик по полосе «Приостановлено».
4. Модель простаивает и поле пустое — два Enter подряд принудительно продолжают
   работу без пользовательского сообщения.
5. Повторное нажатие «Пауза вкл.» выключает паузу и отпускает текущую точку.

## Конфигурация

`defaultEnabled` (по умолчанию `false`):

```yaml
plugins:
  pause-ru:
    defaultEnabled: false
```

## Отличия от апстрима

| | dsh-pause 0.1.8 | pause-ru |
|---|---|---|
| Язык UI | китайский | русский |
| Пакет / bundle id | `dsh-pause` | `@dsh-plugins/pause-ru` / `pause-ru` |
| RPC-канал | `/dsh-pause` | `/pause-ru` |
| peerDependencies | `^0.2.0-rc.2` | `^0.2.2-rc.1` |

Хуки, формат RPC, раскладка файлов и поведение не менялись. Комментарии
в собранных бандлах остались на языке апстрима — это исходники, а не UI.
